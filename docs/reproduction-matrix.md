## Status interpretation

- **Implemented** means the code follows the requirement at the stated level; it does not imply the full paper experiment has been run.
- **Partial** means some elements exist but evidence, configuration, or evaluation differs.
- **Assumption** means the PDF does not specify enough detail to verify the implementation choice.
- **Missing / Failing requirement** identifies a necessary change before asserting exact reproduction.
